# Writing rules

## No em dashes

Don't use em dashes (—) or en dashes (–) anywhere in this project. That covers page text, project and review data, meta tags, `manifest.json`, code comments and commit messages.

They make the text read like it was written by AI. Write a normal sentence instead, the way you'd type it on a keyboard: use a period, a comma, "and", "with", or reword it.

Examples from this site:

- `RENSE — Roguelite FPS` became the title `RENSE`, with "Roguelite FPS" moved into the description.
- `Deep mechanics, crisp feel—brutal and beautiful.` became `Deep mechanics and a crisp feel. Brutal and beautiful.`
- `Stevie Wonder’s magnum opus—an ambitious double LP` became `Stevie Wonder’s magnum opus is an ambitious double LP`

Normal hyphens are fine, like `co-founder`, `late-80s` or `R82-0`.
